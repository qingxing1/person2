## 问题排查指南

### 常见问题

1. **滚动不触发折叠**
   - 检查 `window.scrollY` 是否正确获取
   - 验证事件监听器是否正确添加
   - 确认阈值配置是否合理

2. **动画不流畅**
   - 检查 CSS 动画属性
   - 验证 `transform-gpu` 类是否生效
   - 确认浏览器硬件加速是否启用

3. **localStorage 不工作**
   - 检查浏览器是否支持 localStorage
   - 验证隐私模式是否禁用存储
   - 确认存储空间是否充足

4. **移动端体验差**
   - 检查触摸事件处理
   - 验证响应式样式
   - 确认视口设置正确

### 调试工具

```javascript
// 启用调试模式
localStorage.setItem('debug-sidebar', 'true');

// 查看组件状态
console.log('Sidebar state:', {
  isCollapsed: /* 当前折叠状态 */,
  isManuallyControlled: /* 手动控制状态 */,
  scrollY: window.scrollY
});
```
